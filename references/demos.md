## Patterns to Study

### Platformer
- State machine for player movement (idle, run, jump, fall)
- Coyote time and jump buffering
- Tile-based level design
- Camera follow with smoothing

### Top-Down
- Grid-based movement and collision
- Line of sight for enemy AI
- Room transitions
- Object interaction zones

### 3D
- Camera systems (orbit, follow, cinematic)
- Physics interactions and raycasting
- Lighting and materials
- 3D navigation and pathfinding

### UI
- Menu systems with navigation
- HUD overlays with CanvasLayer
- Theming and responsive layouts
- Dialog and inventory UIs

## Recommended Study Order

1. Start with 2D platformer — covers fundamentals
2. Study top-down for grid-based patterns
3. Explore 3D for spatial concepts
4. Examine UI demos for Control nodes
